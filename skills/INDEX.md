# hr-orchestrate skills: index

Pick the row that matches where you are and open that skill's `SKILL.md`.

| Where you are | Skill |
|---|---|
| Just started, lost, or something failed | `hr-orchestrate` |
| Starter repo just dropped (first hour) | `hr-orchestrate-kickoff` |
| Contract is written, time to design and build | `hr-orchestrate-build` |
| Pipeline writes a full CSV, now find and fix wrong rows | `hr-orchestrate-test-fix` |
| Preparing for the AI judge interview (start mid-build) | `hr-orchestrate-interview` |
| Output is final, build and check the submission | `hr-orchestrate-package` |

Order: `hr-orchestrate` → `kickoff` → `build` → `test-fix` → `package`, with `interview` running in parallel from roughly hour 14.

Every script is Python 3.9+ standard library only. Run any of them with `--help`.
